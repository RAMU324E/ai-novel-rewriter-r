1 API 设置

正在读取此手机的 API 配置…

可选请求参数（默认均不发送）
自定义思考 / 推理参数

仅在启用时发送，按顶层浅合并。也可填写 {"thinking":{"type":"enabled","budget_tokens":4096}} 等服务商自定义格式。

生成可靠性

前两个请求模式保持原有互斥；缺标题和正文过短是独立质量检查，可与任一请求模式同时开启。四类原因共用同一重试次数上限；用户停止、配置错误和保存失败不会重复请求。

请求覆盖（专家）

仅影响聊天请求，不影响“拉取模型”。路径相对 Base URL，也可填完整 HTTP(S) URL；请求体最后做顶层浅合并，可改写 model、messages、stream。启用覆盖后可在请求体中自定模型而不拉取模型；GET 不发送请求体。响应仍须兼容当前 OpenAI 格式。

当前 API Key 默认仍会作为 Bearer 头发送；可用 {"Authorization":null} 删除。高级配置保存在此 App；错误 URL 可能把内容发往非预期服务。

DS联网搜索

开启后，章节类请求（处理章节、重 roll、批量、阅读模式）改走 /responses 接口并附带 web_search 工具，由 DeepSeek 在服务端执行搜索后直接给出正文；首楼、摘要请求不受影响。搜索会额外消耗 Token。端点不支持时自动退回普通请求并提示一次。仅对 DeepSeek 官方 API 生效，其他服务商（GLM/Kimi 等）不受此开关影响。

非空时注入到章节尾部处理要求之前，告诉模型什么情况该搜索、怎么用结果；随书籍存档和完整 JSON 一起保存。启用“请求覆盖（专家）”时联网搜索自动不生效。

普通模式只会请求 Base URL；专家模式也可能请求你填写的完整聊天 URL。

5 章节模板
6 语音朗读（MiMo TTS）

开启后，章节生成过程中攒够一段完整句子（默认首段约 100 字、后续段约 200 字，可调）就开始合成朗读，后续段落生成好自动接着读，不用等整章完成。单段上限固定 1200 字。朗读中点「停止朗读」只是暂停，按钮变为「继续朗读」可从暂停处接着播；生成重试或失败时才会整体停止并随新尝试重新开始。仍需上方总开关和 MiMo Key。

只朗读 AI 输出的章节结果；长文自动分段逐段合成、顺序播放。MiMo Key 只保存在此 App 本机配置，不进入书籍存档、完整 JSON 或 TXT。锁屏或切到后台时不保证继续播放。
